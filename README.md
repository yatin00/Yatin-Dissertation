RASCA – Sentiment Classification

This repository contains the code developed for my MSc Data Science and Artificial Intelligence dissertation on Reliability-Aware Sentiment Classification and Analysis (RASCA).

Dataset

The project uses the Sentiment140 dataset for binary sentiment classification of social media posts.

Methods

•⁠  ⁠Text preprocessing
•⁠  ⁠TF-IDF using unigrams and bigrams
•⁠  ⁠Logistic Regression
•⁠  ⁠Multinomial Naive Bayes
•⁠  ⁠Linear SVM
•⁠  ⁠Random Forest

Evaluation

The models are evaluated using:

•⁠  ⁠Accuracy
•⁠  ⁠Precision
•⁠  ⁠Recall
•⁠  ⁠F1-score
•⁠  ⁠ROC-AUC
•⁠  ⁠PR-AUC

The project also includes Brier Score, calibration analysis, selective prediction, and high-confidence error analysis to assess prediction reliability.

Purpose

The aim of the project is to evaluate sentiment classifiers not only by their classification performance, but also by the reliability of their prediction confidence.
